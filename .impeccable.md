## Design Context

### Users
CityOS designers and engineers using Desigma's native editing workspace and CityOS libraries, with access to repository investigation and Codex remediation.

### Brand Personality
Focused, dependable and understated. Retain Desigma's established native application identity.

### Aesthetic Direction
Reuse the current native theme, compact sidebar and existing CityOS workspace. Add clear tools without duplicating navigation or crowding the design canvas.

### Design Principles
- Preserve the ongoing design workflow and existing CityOS entry.
- Expose Atlas investigation and bulk-fix reports through concise, purposeful actions.
- Keep advanced details and diagnostics behind disclosures.
- Use real destinations, normal private sign-in, accessible labels and clear launch errors.
